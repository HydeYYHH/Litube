Litube
============

Litube is an advanced WebView wrapper for YouTube.

Requires Android 6.0 (API 23) or later and an up-to-date Android System WebView. Picture-in-Picture is available on Android 8.0 or later when the device supports it.

### About v3

Thank you so much to everyone who has stayed with this project. Development is moving rather slowly, but it is still active, and the project keeps moving forward.

v3 is a major upgrade from v2: much of the app has been rewritten following modern Android development practices. We are aware that previous versions had many playback issues that were widely discussed, and we apologize for not addressing them sooner. To address them in a more reliable way, we took inspiration from projects like NewPipe and yt-dlp and substantially reworked the underlying implementation. These issues have now been greatly reduced, and both stability and speed have improved considerably.

We have also refined many parts of the UI and user experience, and added support for older Android versions.

That said, v3 is still built around a WebView wrapper. We are already planning v4, in which the project will be further rewritten with native Android technologies, gradually replacing the WebView-based architecture.

## Features
* [x] **Ad-free playback**
* [x] **Sponsor-block**
* [x] **Mini-player support**
* [x] **Local queue support**
* [x] **Background & Picture-in-Picture support**
* [x] **Built-in video and playlist downloader**
* [x] **Live stream chat support, etc.**
